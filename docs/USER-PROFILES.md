# Workspace MKT
## Perfis de Usuário

Status: Definido

---

# Conceito

O Workspace MKT possui uma única interface.

O que muda entre os usuários é:

- Menus disponíveis
- Visualizações disponíveis
- Dashboard padrão
- Permissões
- Ações permitidas

A experiência deve permanecer consistente entre todos os perfis.

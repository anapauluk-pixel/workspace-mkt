# Workspace MKT
## MVP - Produto Mínimo Viável

Status: Definido

---

# Objetivo do MVP

Entregar uma primeira versão funcional do Workspace MKT capaz de:

- Organizar demandas de Marketing
- Permitir acompanhamento operacional
- Centralizar informações das demandas
- Validar fluxo de trabalho da equipe
- Validar experiência de uso
- Validar arquitetura para futura integração com o GLPI

---

# Escopo do MVP

O MVP possui foco operacional.

O objetivo não é entregar todas as funcionalidades previstas no PRD.

O objetivo é validar o núcleo do produto.

# Critério de Sucesso

O MVP será considerado validado quando:

- A equipe conseguir operar demandas reais
- O fluxo completo for concluído dentro do Workspace MKT
- As visualizações forem utilizáveis
- O processo de aprovação estiver funcional
- O time aprovar a experiência de uso
- A arquitetura estiver pronta para integração futura com o GLPI
